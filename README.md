# VERESK — проект «Руки»

Статический сайт на HTML, CSS и JavaScript. Публичные файлы находятся в `dist/`.

Возможности: адаптивная навигация, поиск по архиву 57 встреч, раскрытие архива, горизонтальная галерея, просмотр фото в диалоге с клавиатурным закрытием, FAQ, прямые ссылки для заказа через Telegram и email, ссылки на соцсети и публикации.

Контакты и фотографии предоставлены владельцем. Источники и ограничения исследования — в `RESEARCH.md`.

`node check.cjs` проверяет структуру, данные и локальные ссылки. `node --check dist/app.js` проверяет синтаксис JavaScript.

Служебные скрипты `integrate-media.cjs` и `label-photos.cjs` использовались для однократной сборки содержания; не запускать их повторно поверх готовой страницы. Редактировать содержимое в `dist/index.html`. Даты и имена хранятся также в `dist/people.json`.

Не установлены: стоимость, точная география выездов и сроки. Посетитель согласовывает их напрямую с автором. Формы сбора персональных данных, оплата и аналитика не подключены.
